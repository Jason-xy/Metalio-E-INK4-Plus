02 / 05 · DATA SOURCE

连接数据站点

一个 Sub2API 站点。先测试草稿，再保存；保存成功前继续使用旧配置。

手机到设备使用HTTP明文传输，管理员Key可能被同网设备读取。仅限可信局域网；Key不回读或导出，设备实物需由你控制。

测试只验证设备与站点的TLS、认证和接口，不触发供应商额度采样。站点数据库统计分桶必须使用UTC+8。

03 / 05 · USER

监控用户

一次选择一个用户；保存前只修改草稿，额度账户不随用户切换。

04 / 05 · ACCOUNTS

选择额度账户

只显示勾选的账户。默认读取已有快照，供应商采样在设备上逐账户手动触发。

“尚未采集”“未提供”和“上次手动结果”分别标示，缺失额度不等于0%。最多选择64个账户。
